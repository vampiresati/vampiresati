Building a human-in-the-loop Git merge workflow with local LLMs

One useful AI automation pattern is to keep the model close to the code, but keep the final decision with a human. For ticket-based development, that means an agent can inspect branches, summarize diffs and prepare tests while a developer or project lead approves the merge.

Workflow

  • Merge PHP and frontend ticket branches locally.
  • Analyze Git diffs and identify affected files, screens and workflows.
  • Generate an impact report for review.
  • Ask for human confirmation before continuing.
  • Create a test plan and optionally run browser checks with Playwright.

Why local LLMs help

Local models are useful for private review workflows because the project context can remain on the machine. The model does not need to be perfect; it needs to prepare a useful first pass that makes human review faster and more consistent.
